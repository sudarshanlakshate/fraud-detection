# Credit Risk and Fraud Detection

Standalone fraud-detection project using the IEEE-CIS Fraud Detection benchmark.

## Data

Downloaded source files belong under `data/raw/`. Raw, interim, and processed datasets are excluded from Git. Do not commit or redistribute source data. Record the exact source revision, terms, and checksums before ingestion.

See [dataset card](docs/data/DATASET_CARD.md), [schema and field families](docs/data/DATA_SCHEMA.md), and [ingestion contract](docs/data/INGESTION_CONTRACT.md).
